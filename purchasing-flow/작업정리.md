# 원료 구매 분석 화면 후속 작업

PDF 대화의 마지막 합의는 a를 a-1과 a-2로 분리하고 이후 b, c 순서로 이동하는 구조입니다. 이번 작업에서는 b를 구체화하고 공통 메뉴·조건 유지가 작동하는 로컬 HTML 시안을 만들었습니다.

## 화면과 동작

- 설정: PP/EVA 원료 선택 및 구성비 저장. 구성비 합계 검토. 제품 원가 계산에는 아직 사용하지 않음.
- a-1: 시장가, 원료/환율 이중 축 비교, SAP 예시 단가 비교, 계약 형태 및 즉시/분할/보류 이력.
- a-2: 환율, 원화 환산 단가, 일별/월별 환율·구매 수량 비교, 경제지표 검토 항목. 최신 경제지표 수치는 미입력.
- b: 원료/기간 필터, 뉴스 긍정·부정·중립 분포, 분류 근거 표, 원료 가격 MACD와 환율 MACD 두 차트.
- c: a/b 결과 요약과 시나리오 검토 조건. 예측 규칙 미정이므로 날짜·수량 추천은 미산출.

공통 선택값은 브라우저 localStorage에 저장합니다. 첫 화면은 전체 플로우입니다. 좌측 메뉴의 첫 항목으로 배치했으며, 플로우의 a-1/a-2/b/c 박스를 클릭하면 해당 화면으로 이동하고 좌측 메뉴가 선택됩니다. HTML 파일을 브라우저에서 열면 별도 설치나 외부 스크립트 없이 동작합니다.

## 계산과 데이터 범위

모든 가격·환율·구매 이력·뉴스 제목은 가상 예시입니다. S&P/SAP/뉴스/경제지표 서비스에 연결하지 않았습니다. 분류 결과는 화면 검토용으로 입력한 값이며 감정 분석 모델을 실행한 결과가 아닙니다. 긍정 뉴스 비율을 구매 추천 점수로 사용하지 않습니다.

MACD는 일별 예시 시계열의 EMA(12)-EMA(26), Signal은 MACD의 EMA(9), Histogram은 MACD-Signal입니다. EMA는 첫 예시 관측치를 초기값으로 사용합니다. 선택 시작일 이전 데이터로 계산한 뒤 선택 기간을 표시합니다. 거래일 달력은 적용하지 않았습니다.

원화 환산 단가는 USD/ton × KRW/USD입니다. 실제 도착원가와 구분하며 운임·관세·기타 비용은 포함하지 않습니다. 월별 환율은 선택 기간의 관측치 평균, 수량은 기간 내 구매 합계입니다. 구성비는 저장만 하며 원가 산식에 적용하지 않습니다.

금리 인하·금융 위기는 경제지표 맥락에 포함했습니다. 원재료 공급·수급 항목은 PDF의 사용자 정정에 따라 제외했습니다.

## 실제 데이터 연결에 필요한 항목

1. S&P 가격: 기준 일자, 원료 코드, 등급/지역, 가격, 통화, 단위, 출처.
2. SAP 구매: 계약 일자, 실제 발주/입고 일자, 원료 코드, 계약 형태, 실행 방식, 수량, 단가, 적용 환율, 취소 여부.
3. 환율: 기준 일자, 통화 쌍, 관측 시점, 기준환율/계약환율 구분.
4. 뉴스: 기사 식별자, 원문 URL, 발행 시각, 원료 태그, 제목, 본문, 분류·근거 문구·모델 버전·신뢰도.
5. 경제지표: 지표 식별자, 국가, 관측 기간, 발표 시점, 수치·단위·출처.

## 이어서 결정할 내용

- b의 감정 분석 기준: 기사 분위기, 가격 방향, 구매 유불리를 서로 구분할지와 각 표시 방법.
- 실제 데이터의 단위·통화·등급·지역을 맞추는 규칙과 환율 적용 시점.
- c의 예측 기간, 재고/소요량/납기 입력, 즉시·분할·보류 판단 규칙, 최종 구매 시점 산출 방식.

이 파일과 index.html은 원본 PDF와 별도로 작성했습니다. 기존 market-health-dashboard는 수정하지 않았습니다.
